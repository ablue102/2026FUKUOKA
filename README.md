# 2026 九州親子旅行

免安裝依賴的 HTML / CSS / JavaScript 手機旅行手冊。

## 開啟
直接用瀏覽器開啟 index.html，或在此資料夾執行 `node server.cjs`，瀏覽 http://127.0.0.1:2026 。本機伺服器僅供自己預覽。

## 修改資料
所有旅遊內容集中在 itinerary.js 的 TRIP.days。每一天包含日期、星期、主題、路線、driveTime、hotel、highlights、alerts 及 timeline。原始 rows 每行使用以下欄位：
時間 | 活動名稱 | 地點 | 交通方式 | 預計車程 | 備註
啟動時統一轉成 timeline 物件。修改航班預設值使用 flight.value；Day 1 和 Day 6 也可在畫面修改航班時間，保存在瀏覽器，並更新對應航班節點。後續行程不自動重排，須自行調整 rows。

Day 3 的 alternativePlan 為可收合備案。飯店、餐廳及尚未確認的安排未填入虛構店家。

## 路由與保存
首頁 #/；每日獨立路由 #/day/1 到 #/day/6。可直接分享帶有路由的網址。
行程與清單使用 localStorage（kyushu-2026）保存在同一瀏覽器、同一網址，不跨裝置同步。變更時間軸順序後，舊勾選可能對應不同節點，必要時清除該網站儲存資料。

## 檔案
index.html：入口；style.css：響應式視覺；app.js：路由、互動與保存；itinerary.js：行程資料；server.cjs：本機預覽；package.json：啟動指令。

網站不需要 API 金鑰。MAP 使用 Google Maps 搜尋連結，需要網路；其餘內容不依賴遠端字型、圖片或套件。去程起飛時間為台灣時間；日本境內行程與回程起飛時間為日本時間。旅程內容依使用者提供的規劃建立，未宣稱即時營運、天氣、火山及道路狀態已查證。

已更新航班：9/24 BR106 08:10，座位 52A–52C；9/29 BR105 12:20，座位 47A–47C。去程 11:20 抵達日本，回程 13:45 抵達台灣；Day 1 落地後行程已依 11:20 重新預排。flight 的 number、seats、timezone 可修改航班號、座位及時區；revision 變更可避免舊版儲存時間覆蓋新資料。
